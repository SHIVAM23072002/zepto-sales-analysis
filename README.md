Zepto Sales Dashboard - Power BI Project

This project is a data analysis dashboard built in **Power BI**, focusing on sales insights for Zepto's fast delivery model. The dashboard visualizes key performance indicators, sales trends, and item-wise breakdowns across different outlet types and locations.

Key Insights

- **Average Sales:** $142  
- **Total Sales:** $412K  
- **Average Rating:** 4  
- **Total Items:** 3K  

Features

Interactive Filters
- **Item Type**: Multi-select dropdown
- **Outlet Size**: Small (selected in the current view)

Visual Highlights
- **Sales Trend (2010–2020)**: Line and area chart showing year-wise sales growth.
- **Item Type Analysis**: Horizontal bar chart showing total sales by item category.
- **Fat Content Pie & Bar Charts**: Visual split between *Low Fat* and *Regular* items.
- **Outlet Tier Analysis**: Sales segmented by Tier 1, 2, and 3 locations.
- **Outlet Type Table**: Summary of outlet-wise sales, rating, item visibility, and count.

Tools Used

Power BI** for dashboard creation and interactivity
Excel/CSV data** as the backend (assumed)
Zepto-inspired dataset** for a real-time grocery delivery model
